# PGPC Library Design System

The user has specified a detailed design direction for the PGPC Library project. Adhere strictly to these color tokens and design principles for all UI components.

## CORE COLORS
- **Primary navy**: `#102B70` (Use for main panels like the sidebar and primary buttons)
- **Dark navy hover**: `#0B225E`
- **Deep overlay navy**: `#071943`
- **Gold accent**: `#FCC719` (Use for highlights, active icons, and primary interactions)
- **White**: `#FFFFFF`
- **Blue progress accent**: `#3B82F6`
- **Main text**: `#0F172A`
- **Label text**: `#334155`
- **Secondary text**: `#64748B`
- **Muted text/icons**: `#94A3B8`
- **Borders**: `#E2E8F0`
- **Hover border**: `#CBD5E1`
- **Soft background**: `#F8FAFC`
- **Pale-blue focus/decorative background**: `#EFF6FF` or `#DBEAFE`
- **Error background**: `#FEF2F2`
- **Error border**: `#FECACA`
- **Error text**: `#B91C1C`
- **Required/error red**: `#EF4444`

## TYPOGRAPHY & FEEL
- Use **Open Sans** throughout.
- Interface should feel institutional, modern, trustworthy, welcoming, and academically professional.
- Avoid generic dashboard styling, excessive gradients, excessive shadows, and overly decorative effects. 
- Stick to clean lines, solid branding colors, and subtle glass-style overlays (e.g., `bg-white/10` for active sidebar states).

## COMPONENTS
- **Form Inputs**: 56px height, 16px border-radius, left-side outline icons, navy border on focus with soft 4px pale-blue ring.
- **Buttons**: Primary buttons are navy (`#102B70`) with white text and 16px border radius.
